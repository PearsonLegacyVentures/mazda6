# Mazda6 3D model asset

Place the selected web-ready model here as:

`public/models/mazda6.glb`

The configurator now attempts to load that file automatically. If it is missing or fails to load, the app falls back to the geometry proxy.

## Preferred asset
- Format: GLB
- Keep textures embedded when possible
- Target web size: ideally under 15 MB
- Body length normalized in-app
- Remove unnecessary interior/underbody geometry only after visual inspection
